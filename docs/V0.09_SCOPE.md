# Eidome v0.09 — Anatomy Explorer

v0.09 turns the validated anatomy introduced in v0.08 into an interactive
reference layer without changing the underlying avatar or claiming medical
personalization.

## Included

- Tap hit-testing for bundled muscle and skeleton geometry
- Human-readable structure names derived from the exported source nodes
- Left/right identification when present in the source name
- Compact structure card with anatomical category and provenance
- Selection feedback that does not modify shared materials
- Procedural anatomy fallback remains available
- Version 0.0.9 / build 9
- Existing review-readiness and SceneKit asset validation remain mandatory

## Explicitly deferred

- Medical advice, diagnosis, pain interpretation or injury-risk claims
- Claiming that a selected structure matches the user's measured anatomy
- Structure search, isolation, hide/show controls and multi-select
- Linking movement, mobility or training load to specific tissues
- Camera-based movement capture and coaching
- Public release until v0.08 visual review and third-party licensing review are complete

## Acceptance checks

1. Body and Joints behave exactly as in v0.08.
2. Muscle and Skeleton layers load the bundled USDZ.
3. Tapping visible anatomy returns the correct readable name and side.
4. Drag-to-rotate and pinch-to-zoom continue to work, and each layer restores its own camera state when revisited.
5. Changing layers clears stale selections.
6. The selection is described as reference anatomy, not measured anatomy.
7. Debug build, static analysis and unsigned Release archive pass in CI.
