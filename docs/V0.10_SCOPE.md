# Eidome v0.10 — Anatomy Focus

v0.10 turns structure identification into deliberate visual exploration. A selected
anatomical structure can be focused without changing the underlying reference anatomy or
implying that the structure is measured from the user.

## Included

- Focus action on muscle and skeleton selection cards
- Specific tissue classification for muscles, fascia, tendons, aponeuroses, retinacula, ligaments, bones and cartilage
- Non-selected structures dimmed without modifying shared materials
- Reveal-beneath action for fascia that exposes selectable superficial structures
- One-tap restoration of temporarily hidden anatomy and the complete layer
- Independent camera rotation and zoom retained for every body layer
- Selection, focus and camera state cleared safely when profiles change
- Version 0.0.10 / build 10
- Existing review-readiness and SceneKit validation remain mandatory

## Trust boundary

- Anatomy remains reference data with height-scaled or estimated proportions
- Focus is a visualization state, not a diagnosis, injury marker or measurement
- No medical recommendations or tissue-health claims are introduced

## Acceptance checks

1. Tapping different visible muscles, fasciae or bones updates the structure card.
2. Focus dims surrounding structures while leaving the selected structure visible.
3. Show full layer restores every structure.
4. Switching layers clears selection and focus.
5. Each layer restores its own rotation and zoom when revisited.
6. Body and Joints behavior remains unchanged.
7. Debug build, static analysis and unsigned Release archive pass in CI.

## Explicitly deferred

- Complete deep-muscle compartments; the current mobile USDZ contains the source atlas's superficial-muscle collection
- A dedicated superficial/deep/vascular/nerve layer stack, planned for v0.11
