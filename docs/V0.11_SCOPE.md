# Eidome v0.11 — Explorer UX

## Product outcome

Eidome should help someone understand their body, why it moves the way it does, and what to improve next.

This release improves the path through the 3D twin without adding new anatomy data:

1. **Body** — understand the current personalized estimate and improve it with measurements.
2. **Anatomy** — inspect reference muscles, fascia, tendons and bones, with explicit Muscles/Skeleton sublayers.
3. **Joints** — connect estimated joint locations to the user's recorded mobility.

## Included

- Three purpose-led explorer modes: Body, Anatomy and Joints
- Muscles and Skeleton as Anatomy sublayers
- Mode-specific title, explanation and action
- Visible interaction guidance
- Explicit 3D camera reset
- Preserved camera state between layers
- Clear hidden-structure state and restore action
- Existing anatomy selection, focus and reveal behavior
- Accessibility labels and selected-state semantics
- Version 0.0.11, build 11

## Not included

- New anatomy meshes or deeper anatomical segmentation
- Medical or diagnostic claims
- Exercise prescriptions
- HealthKit, accounts, cloud sync or video analysis
- Persistence of camera state across app launches

## Acceptance checks

- Body, Anatomy and Joints are the only top-level explorer choices.
- Anatomy exposes Muscles and Skeleton without losing the last anatomy choice.
- Body displays the measurement-refinement action.
- Joints displays the mobility action.
- Anatomy displays structure-selection guidance and cards.
- Switching modes preserves each layer's rotation and zoom.
- Reset returns only the current layer to its default camera.
- Hidden anatomy can always be restored.
- Reference anatomy is never described as measured or scanned.
