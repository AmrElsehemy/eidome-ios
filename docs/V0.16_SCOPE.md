# Eidome v0.16 — Joint Explorer

## Why

The previous joint view showed glowing points on a mannequin without enough anatomical context or a useful connection to the user's data.

## App Store user outcome

Users can locate a major joint on the reference skeleton, understand the movements it supports, and see or update the mobility value they entered for that side.

## Release scope

- Replace the mannequin joint layer with the bundled reference skeleton
- Add selectable left/right shoulder, elbow, wrist, hip, knee, and ankle landmarks
- Support both direct 3D selection and searchable landmark browsing
- Explain major supported movements in plain language
- Display matching entered ankle, hip, and shoulder mobility values
- Link a selected landmark to mobility entry
- Preserve the persistent per-profile joint camera from v0.15

## Acceptance criteria

- [x] Joint mode displays the reference skeleton, not the exterior mannequin
- [x] Twelve bilateral landmarks are visible and selectable
- [x] Landmark browser supports search, side, and category
- [x] Shoulder, hip, and ankle cards show the corresponding entered value when present
- [x] Elbow, wrist, and knee cards honestly state that no input field exists yet
- [x] Joint cards distinguish estimated location from entered measurement data
- [x] Joint mode includes no diagnosis or normal-range claim
- [ ] Confirm landmark alignment and tap targets on a physical iPhone

## Trust boundary

Landmarks are estimated positions aligned to a height-scaled reference skeleton. Mobility values are user-entered measurements, not values produced by the model and not a clinical assessment.
