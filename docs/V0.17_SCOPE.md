# Eidome v0.17 — Measured Body Map

## Why

A realistic avatar is not useful by itself. Body mode needs to explain which user inputs shaped the estimate and what remains inferred.

## App Store user outcome

Users can select a body region, see whether its measurement was entered or estimated, inspect the latest value and date, and understand how it changes the twin.

## Release scope

- Add selectable markers for all seven regional body measurements
- Add a searchable body-measurement browser
- Show value, source, recording date, and model effect per marker
- Distinguish entered measurements from model estimates
- Recommend the next useful missing input
- Save an update timestamp whenever regional measurements are saved
- Decode existing profiles that predate the timestamp without data loss

## Acceptance criteria

- [x] Shoulder, chest, waist, hip, inseam, thigh, and calf markers are selectable
- [x] Entered values display in centimetres with entered provenance
- [x] Missing values display as estimates without fabricating a number
- [x] New saves record a measurement update date
- [x] Older saved measurements display “Date not recorded”
- [x] Each card explains the input's model effect
- [x] The why card names the next useful missing measurement
- [ ] Confirm marker placement and tap targets on a physical iPhone

## Trust boundary

The exterior is a model estimate, not a scan. Entered circumferences refine visual proportions but do not measure body composition, tissue health, or internal anatomy.
