# Eidome v0.18 — Evidence-backed Anatomy Knowledge

## Why

Identifying a mesh is not enough. A user needs concise, sourced context that connects a structure's location and function to movement without turning the app into a diagnostic tool.

## App Store user outcome

Selecting a high-value muscle or bone now explains where it is, what it primarily does, why it matters to movement, and where to read the supporting educational reference.

## Release scope

- Add 55 curated knowledge entries covering high-value muscles, muscle parts and bones
- Show region, primary function and movement relevance in the selection card
- Link entries to relevant OpenStax Anatomy & Physiology 2e sections
- Retain an honest general-reference fallback for unmatched source meshes
- Enforce a minimum of 50 curated entries in review-readiness CI

## Acceptance criteria

- [x] At least 50 high-value source structures have curated content
- [x] Covered muscle cards explain region, function and movement
- [x] Covered bone cards explain region, role and movement relationship
- [x] Every curated card has an external educational citation
- [x] Citation links open the source page
- [x] Unmatched structures do not receive guessed structure-specific claims
- [x] Cards repeat the non-diagnostic reference-anatomy boundary
- [ ] Review a representative sample with a qualified anatomy reviewer before commercial release

## Sources

The initial catalog uses OpenStax Anatomy & Physiology 2e sections 7.1, 8.2, 8.4, 11.3, 11.5 and 11.6. The content is concise educational synthesis, not copied textbook prose.

## Trust boundary

Knowledge cards describe reference anatomy. They do not assess the selected user's anatomy, strength, injury, pain, or tissue health.
