# Eidome v0.19 — Licensed Regional Anatomy

## Why

The licensed anatomy mesh contains useful independent structures, but a full-body surface view makes them hard to discover. Better filters create value without pretending the asset contains anatomy that was not exported.

## App Store user outcome

Users can narrow anatomy by body region and tissue type, find independently selectable calf, thigh, shoulder, and forearm structures, and inspect the exact source and licence of what they are viewing.

## Release scope

- Add six regional anatomy filters plus an all-regions view
- Add muscle versus connective-tissue filters for the superficial muscle layer
- Apply filters to both the 3D scene and searchable browser
- Add pinned-source and CC BY-SA 4.0 provenance to selection cards
- Pin the bundled anatomy USDZ SHA-256 checksum
- Validate representative independently named structures in CI

## Acceptance criteria

- [x] Region filters hide unrelated source structures in the model and browser
- [x] Tissue filters separate muscle from connective surfaces
- [x] Calf, thigh, shoulder, and forearm each expose multiple independent structures
- [x] Selection cards show source and licence
- [x] CI rejects an altered USDZ checksum
- [x] CI rejects loss of representative regional structures
- [x] UI and documentation avoid claiming a complete deep-anatomy atlas
- [ ] Confirm filter transitions and selected-object clearing on a physical iPhone

## Trust and licence boundary

This release reorganizes the existing pinned Z-Anatomy / BodyParts3D derivative under CC BY-SA 4.0. The bundled muscle layer is a superficial export. Filtering connective coverings can reveal more of the included muscle geometry, but Eidome does not claim that every deep muscle, tendon, ligament, nerve, or organ is present.
