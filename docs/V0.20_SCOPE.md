# Eidome v0.20 — Guided Body Measurements

## Why

A number without a repeatable protocol has weak meaning. Guided capture makes body inputs easier to perform consistently and gives future comparisons essential context.

## App Store user outcome

Users can follow a landmark cue, enter a value in their preferred unit, record side/date/method/confidence, validate it, and retake it later. The twin updates from the canonical centimetre value.

## Release scope

- Add a dedicated guide for each of the seven regional body measurements
- Show a visual landmark cue plus concise positioning instructions
- Support centimetres and inches with canonical centimetre storage
- Record side for inseam, thigh and calf inputs
- Record capture date, method and confidence
- Validate measurement-specific plausible ranges
- Support retake and clear actions
- Surface provenance details in Body-mode measurement cards
- Preserve decoding of older profiles without metadata

## Acceptance criteria

- [x] Every regional input opens a guided protocol
- [x] Unit switching preserves the same physical value
- [x] Bilateral measurements require left or right side
- [x] Future dates and out-of-range values cannot be saved
- [x] Saved records include date, unit, side, method and confidence
- [x] Retake clears the pending value and stamps today before resave
- [x] Clear removes both value and its metadata
- [x] Body mode shows method, confidence and record date
- [x] Legacy values remain readable and are labeled when details are absent
- [ ] Confirm keyboard, VoiceOver order and tap targets on a physical iPhone

## Trust boundary

Guidance improves consistency but does not turn Eidome into a calibrated measurement device, body scan, body-composition tool, or medical assessment.
